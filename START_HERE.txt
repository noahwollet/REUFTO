REU FTO WEBSITE — MANUAL GITHUB UPLOAD

1. Unzip REUFTO_GitHub_Upload.zip on your computer.
2. Open https://github.com/noahwollet/REUFTO
3. Choose Add file > Upload files.
4. Drag the extracted contents into GitHub, including the docs folder. Keep the folders together. Upload the contents, not the ZIP itself and not an extra outer folder.
5. Commit the files to main.
6. Open Settings > Pages.
7. Under Source, choose Deploy from a branch.
8. Choose branch main and folder /docs, then Save.
9. Wait for GitHub's Pages build to finish. The expected website address is:
   https://noahwollet.github.io/REUFTO/

SUPABASE SIGN-IN SETUP
The frontend already points to your separate REU FTO Supabase project. Do not replace the publishable key with a service-role or secret key. The backend has already been deployed; do not rerun the SQL setup files on the existing database.

In the REU FTO Supabase dashboard, open Authentication > URL Configuration.
Set Site URL to https://noahwollet.github.io/REUFTO/
Add the same address to Redirect URLs and save.

Open the published website, use Create assigned account with your assigned Admin email, confirm the email, and return to sign in. Set your own password; no shared or default password is included. Admins assign additional employee roles inside the academy. A new registration alone grants no employee role.

Before onboarding employees, configure your production email delivery in Supabase; the default email service has recipient and rate limits.

EMAIL VERIFICATION FOR ALL ROLES
In Supabase Authentication > Email Templates > Magic Link, include {{ .Token }} in the email body and save. All roles sign in with their password, request a code, and enter it on the website. Verification lasts up to 15 days for that live sign-in; a new browser session or signing out requires a new code. The emailed code itself expires according to Supabase OTP settings, not after 15 days.
